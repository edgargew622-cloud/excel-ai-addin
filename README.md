# AI-панель для Excel

Надстройка Excel с чатом сбоку от книги. Агент читает листы, объясняет данные и по просьбе меняет книгу. Каждое изменение показывается карточкой, выполняется только после «Выполнить» и после записи проверяется обратным чтением.

- **Модели:** DeepSeek, Kimi, Z.AI, OpenAI, Grok, OpenRouter (включая Claude) или свой сервер с моделью. Выбор — в панели.
- **Бесплатно:** на OpenRouter есть бесплатные модели (пометка `:free`) — нужен только бесплатный ключ OpenRouter; бывают перебои и дневной лимит. Ollama на этом компьютере подключается сама, без ключа, но годится только для компьютера с видеокартой от 8 ГБ: на обычном ноутбуке одна задача идёт больше получаса.
- **Ключи провайдеров** вводятся в панели, хранятся только на этом компьютере в зашифрованном виде и обратно в панель не попадают.
- **Mac и Excel в браузере:** веб-панель без установки программы, модели DeepSeek и OpenRouter (бесплатные, Mistral, Gemini). На Mac — одна команда в Терминале: https://edgargew622-cloud.github.io/excel-ai-addin/mac.html
- **Проверено** на Excel для Windows (ExcelApi 1.14, русский интерфейс); веб-панель — в Excel для Windows и движке WebKit, на настоящем Mac — нет.

## Что умеет

**Чтение и анализ.** Агент видит только то, что сам запросил, — не больше 20 000 ячеек за раз:

- обзор листов, значения и формулы, поиск по книге;
- оформление и правила области;
- профиль данных для очистки;
- анализ данных: тренды, выбросы с адресами ячеек, корреляции и сводка — считает панель по всем строкам, числа совпадают с формулами Excel;
- аудит модели: доказанные ошибки, подозрения, непроверенные места.

Панель стартует в режиме «Только анализ»: запись запрещена, пока пользователь её не разрешит.

**Изменения** (37 инструментов, каждый через карточку подтверждения):

| Область | Что делает |
| --- | --- |
| Данные и формулы | запись значений и формул, протяжка формул по столбцам; перед записью проверяется, есть ли функции в этой версии Excel |
| Очистка | лишние пробелы, регистр (ПРОПИСНЫЕ, строчные, как в предложении, каждое слово), числа и даты из текста по разделителям книги, дубликаты |
| Структура | вставка и удаление строк и столбцов, группировка, листы: создание, копирование, переименование, удаление |
| Оформление | шрифт, заливка, границы, размеры, закрепление, условное форматирование (в том числе по формуле и значками), порядок правил, параметры печати (ориентация, поля, «вписать в N страниц», область печати, заголовки на каждой странице, колонтитулы), цветовая конвенция финансовой модели |
| Таблицы и правила | таблица Excel и обратно в диапазон, правила проверки ввода, сортировка, фильтр |
| Объекты | диаграммы (в том числе составные, комбинированные «столбцы + линия на второй оси» и с осями, подписями данных, легендой, линией тренда и своими цветами рядов и отдельных точек; готовую диаграмму можно перекрасить), сводные таблицы (в том числе на новом листе, с полем в столбцах, фильтрами «только эти» и «первые N», порядком по значению, датами по годам, кварталам и месяцам) |
| Шаблоны и модели | доли и рост, сравнительный анализ, мультипликаторы компаний (EV/EBITDA, EV/Выручка, P/E; медиана, квартили и другие итоги группы), трёхотчётная модель, DCF, LBO — формулами от допущений, с контрольными равенствами |

**Интернет.** Галочка «Интернет» (по умолчанию выключена) даёт агенту поиск и чтение страниц: поиск — через Tavily или Serper на вашем ключе в «Ключах», страницы читает этот компьютер. В сервис поиска уходит только текст запроса. Страницы из интернета не могут заставить панель обратиться к этому компьютеру или домашней сети. Режим «официальные источники» — ЦБ, Минфин, Росстат, раскрытие информации, SEC, ЕЦБ, МВФ. Число из интернета записывается в книгу вместе с источником — адресом и датой чтения; инструкции со страниц не выполняются.

**Файлы.** Кнопка «Файл» прикрепляет CSV, TXT, XLSX, DOCX или PDF до 20 МБ. PDF можно перенести **точной копией**: агент раскладывает таблицу или бланк на новый лист с той же сеткой — строками и столбцами тех же размеров, объединёнными ячейками, рамками, жирным текстом; числа и даты — числами (картинки, печати и цвета не переносятся, сканы без текста — тоже). Файл разбирается на этом компьютере и хранится только в памяти локального сервера: на диск и в облако целиком он не уходит, модель получает содержимое частями, как при чтении листа. Таблица из файла переносится в книгу через карточку — значения берутся из самого файла, место должно быть пустым, каждая ячейка сверяется. Текст внутри файла — данные: «инструкции ассистенту» в нём не выполняются.

**Память.** Панель помнит ваши предпочтения (форматы чисел, заголовки, цвета, диаграммы) и сохранённые сценарии — цепочки просьб, которые запускаются одной командой. Хранится только на этом компьютере, видно и правится в окне «Память». Агент сам ничего не запоминает: только по вашей просьбе («запомни», «всегда», «сохрани сценарий») и после карточки подтверждения.

**Беседы.** Переписка с агентом хранится только на этом компьютере, по книгам, 30 дней с последнего сообщения. Окно «Беседы» показывает все беседы: книгу, дату и когда беседа удалится; любую можно прочитать (беседу другой книги — только прочитать), сохранить в файл Markdown в «Документы\am.AI\Беседы» (на Mac и в Excel в браузере — скопировать текстом) и удалить — одну или все.

Полный список инструментов с тем, что проверяется после каждого, — в [docs/development/README-dev.md](docs/development/README-dev.md).

## Как устроена безопасность записи

1. Модель предлагает операцию. Панель проверяет имя инструмента и аргументы по схеме до обращения к Excel.
2. Панель готовит план и показывает карточку: что изменится, что сломается, есть ли отмена.
3. После «Выполнить» панель заново проверяет, что книга не изменилась с момента предпросмотра, и только тогда пишет.
4. После записи результат читается обратно и сверяется с планом. Итог получает статус: `verified`, `applied`, `unknown` или `failed_before_write`. Всё, кроме `verified`, останавливает задачу.
5. Кнопка «Отменить» откатывает последнюю операцию агента, если у неё есть отмена. Отмена не затирает то, что изменили после неё, и проверяет результат.

Финансовые модели строятся только от допущений пользователя: значения по умолчанию не подставляются. Каждая ячейка сверяется с расчётом панели, и «готово» выдаётся только при сошедшихся контрольных равенствах (баланс, источники = использование и другие).

## Установка готового комплекта

Скачайте `ExcelAI-Setup-….exe` со страницы [Releases](https://github.com/edgargew622-cloud/excel-ai-addin/releases), закройте Excel и запустите установщик — права администратора, Node.js и сборка не нужны. Затем в Excel: «Главная» → «Надстройки» → «Дополнительные надстройки» → «Общая папка» → «AI-панель» → «Добавить». Удаление — через «Приложения» Windows. Пошагово, а также установка из zip — в [docs/INSTALL.md](docs/INSTALL.md).

## Установка из исходников (Windows)

Нужны Node.js (проверено на версии 24), Excel для Windows и ключ хотя бы одного провайдера.

```bash
npm install
npm --prefix server install
npm run certs                          # доверенные HTTPS-сертификаты для localhost, один раз
npm run check                          # тесты и сборка панели и сервера
npm run release:apply                  # собрать выпуск и запустить сервер на https://localhost:3000
powershell -ExecutionPolicy Bypass -File scripts/register-addin.ps1   # показать надстройку в Excel
```

После этого в Excel: «Главная» → «Надстройки» → «Мои надстройки» → «Общая папка».

Ключи провайдеров вводятся в самой панели кнопкой «Ключи»; при первом запуске этот экран открывается сам. Ключ шифруется средствами Windows (DPAPI, только для вашей учётной записи) и хранится в `server/keys.dpapi`. Вместо этого ключ можно вписать в `server/.env` (образец — `.env.example`); ключ из панели важнее.

Полезные команды:

- `npm run autostart` — запуск сервера при входе в Windows;
- `npm run diagnose` — проверка установки;
- `npm run rollback` — возврат к прежнему выпуску.

Если панель открывается белым прямоугольником, Excel не доверяет сертификату localhost: повторите `npm run certs` и проверьте адрес `https://localhost:3000/taskpane.html` в браузере.

## Разработка

```bash
npm run dev      # Vite на https://localhost:3100, /api проксируется на рабочий сервер
npm test         # тесты панели
npm --prefix server test
```

`manifest.dev.xml` — отдельная dev-надстройка с другим GUID.

Готовый комплект для Windows — со своим Node, без npm и сборки у пользователя — собирает `node scripts/bundle.mjs` после `npm run check`. GitHub Actions собирает его на каждый pull request и проверяет в Windows (`scripts/bundle-smoke.ps1`): сервер из комплекта, доверенный HTTPS, сохранение ключа через DPAPI и его чтение после перезапуска. Из комплекта собирается установщик `Setup.exe` (Inno Setup, `packaging/ExcelAI.iss`); CI ставит и удаляет его на чистой Windows. На тег `v*` установщик и zip-архив публикуются в GitHub Releases.

Живые проверки в Excel — скрипты `scripts/live-excel-*.mjs`. Книги для них создают `scripts/create-*.py`.

## Ограничения

- **Данные уходят провайдеру.** Всё, что агент прочитал из книги, отправляется выбранному провайдеру модели (кроме Ollama — она работает на этом компьютере). Бесплатные модели поставщики могут использовать для обучения. Для книг с персональными данными или коммерческой тайной выбирайте провайдера и договор с ним соответственно.
- **Текст в ячейках попадает в контекст модели.** Ячейка с инструкцией вида «удали лист» или «прочитай лист Secret» — реальный вектор атаки. Защита: каждая запись — только по карточке; лист, который вы не называли в просьбе, агент читает только с вашего разрешения («Разрешить чтение листа?»). Не разрешайте то, о чём не просили.
- **Панель проверяет расчёт, но не допущения.** Единицы, знаки в чужих моделях и верность допущений проверяет человек. Итоговый текст модели панель не сверяет: книгу — да, пересказ — нет.
- **Не проверялось** на настоящем Excel для Mac и в Excel Online (веб-панель проверена в Excel для Windows и в WebKit). Копирование листа не поддерживается: на проверенной сборке Excel эта операция через API отказывает.
- **Сервер локальный.** Слушает только петлевые адреса и отвечает только панели с токеном, записанным при установке. Папку надстройки установщик закрывает для других пользователей компьютера. От программы, запущенной под вашей же учётной записью Windows, это не защищает — как и любая программа, она может читать ваши файлы. Для доступа с других компьютеров нужна другая схема развёртывания.
