# Установка AI-панели для Excel

Для Windows 10 и 11 с Excel для Windows (Microsoft 365, Office 2021 и новее). Node.js, npm и сборка не нужны: всё необходимое уже в комплекте.

## Установка

1. Скачайте **`ExcelAI-Setup-….exe`** со страницы [Releases](https://github.com/edgargew622-cloud/excel-ai-addin/releases).
2. Полностью закройте Excel.
3. Запустите скачанный файл.
   - Установщик не подписан, поэтому Windows может показать «Windows защитила ваш компьютер». Нажмите **«Подробнее»** → **«Выполнить в любом случае»**.
   - Когда Windows спросит, установить ли сертификат, ответьте **«Да»**: без него Excel покажет пустую панель.
   - Запускать от имени администратора не нужно. Надстройка ставится в личную папку `%LOCALAPPDATA%\Programs\ExcelAI`, выбирать папку не надо.
4. Откройте Excel → **«Главная»** → **«Надстройки»** → **«Дополнительные надстройки»** → вкладка **«Общая папка»** → **«AI-панель»** → **«Добавить»**. Это нужно сделать один раз.
5. На вкладке «Главная» появится кнопка **«Открыть чат»**. Нажмите её, затем **«Ключи»**, и вставьте ключ хотя бы одного провайдера (например, DeepSeek). Ключ хранится только на этом компьютере, зашифрованный средствами Windows.

Надстройка регистрируется в Excel через «Общую папку» по адресу `\\localhost\C$\…`. Эта служебная папка доступна только учётным записям с правами администратора — обычно это так на домашних компьютерах. Если у вашей учётной записи Windows таких прав нет, установщик запишет надстройку запасным способом («для разработчика»), но Excel может её не показать. Такой случай пока не поддерживается.

## Обновление

Когда выходит новая версия, панель показывает сверху полосу со ссылкой на неё. Скачайте новый `ExcelAI-Setup-….exe`, закройте Excel и запустите его поверх старой версии. Ключи и настройки сохранятся.

Проверка обновлений — один запрос к GitHub в день. Отключить её можно переменной окружения `UPDATE_CHECK=off`.

## Если что-то не так

- **Нет вкладки «Общая папка» или в ней нет «AI-панели».** Полностью закройте Excel (проверьте, что его нет в диспетчере задач) и откройте снова.
- **Панель — белый прямоугольник.** Excel не доверяет сертификату. Запустите установщик ещё раз и подтвердите установку сертификата.
- **Панель пишет, что сервер недоступен.** Запустите установщик ещё раз: он перезапустит сервер. Журналы — в папке `%LOCALAPPDATA%\Programs\ExcelAI\logs`, итог установки — в `install.log` там же.
- **Проверка установки:** `powershell -ExecutionPolicy Bypass -File "%LOCALAPPDATA%\Programs\ExcelAI\scripts\diagnose.ps1"`.

## Удаление

Закройте Excel, затем откройте **«Параметры Windows»** → **«Приложения»** → **«Установленные приложения»** → **«AI-панель для Excel»** → **«Удалить»**. Удаляются автозапуск сервера, регистрация в Excel и папка надстройки вместе с сохранёнными ключами.

## Установка из zip-архива (для опытных)

На странице выпуска есть и архив `ExcelAI-…-win-x64.zip` — то же самое без установщика.

1. Распакуйте архив в `C:\`: правой кнопкой по архиву → «Извлечь все…» → впишите ровно `C:\` → «Извлечь». Должна получиться папка `C:\ExcelAI`, а в ней сразу — «Установить.cmd». Сервер работает из этой папки, поэтому не удаляйте и не переносите её.
2. Закройте Excel и дважды щёлкните «Установить.cmd». В конце окно напишет «Готово» и будет ждать Enter.
3. Дальше — шаги 4–5 из раздела «Установка».

Удаление: закройте Excel и дважды щёлкните «Удалить.cmd» в той же папке.
