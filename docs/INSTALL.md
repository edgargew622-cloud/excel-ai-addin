# Установка AI-панели для Excel

Для Windows 10 и 11 с Excel для Windows (Microsoft 365, Office 2021 и новее). Node.js, npm и сборка не нужны: всё необходимое уже в комплекте.

## Установка

1. Скачайте `ExcelAI-…-win-x64.zip` со страницы [Releases](https://github.com/edgargew622-cloud/excel-ai-addin/releases).
2. Распакуйте архив в `C:\`:
   1. Откройте папку «Загрузки» и найдите скачанный `ExcelAI-…-win-x64.zip`.
   2. Щёлкните по нему **правой** кнопкой мыши → **«Извлечь все…»**.
   3. В поле с путём сотрите всё и впишите ровно `C:\` → **«Извлечь»**. Если Windows попросит права администратора, нажмите «Продолжить».
   4. Должна получиться папка **`C:\ExcelAI`**, а в ней сразу — файл «Установить.cmd».

   Не вписывайте `C:\ExcelAI` в поле распаковки: внутри архива уже есть папка `ExcelAI`, и получится лишняя вложенная `C:\ExcelAI\ExcelAI`. И не запускайте «Установить.cmd», просто открыв архив двойным щелчком: без распаковки установка остановится и попросит сначала распаковать. Сервер надстройки будет работать из этой папки — не удаляйте и не переносите её после установки.
3. Дважды щёлкните **«Установить.cmd»** в папке `C:\ExcelAI`. Откроется окно установки; в конце оно напишет «Готово» и будет ждать Enter.
   - Windows может спросить, запускать ли файл из интернета, — ответьте «Выполнить».
   - Если Windows спросит, установить ли сертификат, ответьте «Да»: без него Excel покажет пустую панель.

4. Полностью закройте и снова откройте Excel.
5. «Главная» → «Надстройки» → «Мои надстройки» → «Общая папка» → «AI-панель» → «Добавить».
6. Нажмите «Открыть чат», затем «Ключи» и вставьте ключ хотя бы одного провайдера (например, DeepSeek). Ключ хранится только на этом компьютере, зашифрованным средствами Windows.

## Если что-то не так

- **Панель — белый прямоугольник.** Excel не доверяет сертификату. Запустите «Установить.cmd» ещё раз и подтвердите установку сертификата.
- **Панель пишет, что сервер недоступен.** Запустите «Установить.cmd» ещё раз — он запустит сервер и скажет, что мешает. Журналы — в папке `logs`.
- **Установка без двойного щелчка** (например, если .cmd запрещены): `powershell -ExecutionPolicy Bypass -File scripts\install.ps1`.
- **Проверка установки:** `powershell -ExecutionPolicy Bypass -File scripts\diagnose.ps1`.

## Удаление

```powershell
powershell -ExecutionPolicy Bypass -File scripts\register-autostart.ps1 -Remove
```

Затем удалите папку комплекта. В Excel: «Файл» → «Параметры» → «Центр управления безопасностью» → «Параметры центра…» → «Каталоги надёжных надстроек» — удалите строку с адресом этой папки.
