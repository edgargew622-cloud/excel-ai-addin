# Установка AI-панели для Excel

Для Windows 10 и 11 с Excel для Windows (Microsoft 365, Office 2021 и новее). Node.js, npm и сборка не нужны: всё необходимое уже в комплекте.

## Установка

1. Скачайте **`ExcelAI-Setup-….exe`** со страницы [Releases](https://github.com/edgargew622-cloud/excel-ai-addin/releases).
2. Полностью закройте Excel.
3. Запустите скачанный файл.
   - Установщик не подписан, поэтому Windows может показать «Windows защитила ваш компьютер». Нажмите **«Подробнее»** → **«Выполнить в любом случае»**.
   - Когда Windows спросит, установить ли сертификат, ответьте **«Да»**: без него Excel покажет пустую панель.
   - Запускать от имени администратора не нужно. Надстройка ставится в личную папку `%LOCALAPPDATA%\Programs\ExcelAI`, выбирать папку не надо.
4. Откройте Excel → **«Главная»** → **«Надстройки»** → **«Дополнительные надстройки»** → вкладка **«Общая папка»** → **«AI-панель»** → **«Добавить»**. Это нужно сделать один раз.
5. На вкладке «Главная» появится кнопка **«am.AI»**. Нажмите её — откроется чат. В нём нажмите **«Ключи»** и вставьте ключ хотя бы одного провайдера (например, DeepSeek). Ключ хранится только на этом компьютере, зашифрованный средствами Windows.

Надстройка регистрируется в Excel через «Общую папку» по адресу `\\localhost\C$\…`. Эта служебная папка доступна только учётным записям с правами администратора — обычно это так на домашних компьютерах. Если таких прав нет, установщик регистрирует ту же «Общую папку» по адресу `\\localhost@3080\catalog`: её отдаёт сервер надстройки по протоколу WebDAV, а Windows открывает как сетевую папку. Права администратора для этого не нужны, но нужна служба Windows «Веб-клиент» (WebClient) — в Windows 10 и 11 она есть и запускается сама. Если её отключили (так бывает на рабочих компьютерах), установщик запишет надстройку запасным способом («для разработчика»), и Excel может её не показать.

## Обновление

Когда выходит новая версия, панель показывает сверху полосу со ссылкой на неё. Скачайте новый `ExcelAI-Setup-….exe`, закройте Excel и запустите его поверх старой версии. Ключи и настройки сохранятся.

Проверка обновлений — один запрос к GitHub в день. Отключить её можно переменной окружения `UPDATE_CHECK=off`.

## Если что-то не так

- **Нет вкладки «Общая папка» или в ней нет «AI-панели».** Полностью закройте Excel (проверьте, что его нет в диспетчере задач) и откройте снова.
- **Панель — белый прямоугольник.** Excel не доверяет сертификату. Запустите установщик ещё раз и подтвердите установку сертификата.
- **Панель пишет, что сервер недоступен.** Запустите установщик ещё раз: он перезапустит сервер. Журналы — в папке `%LOCALAPPDATA%\Programs\ExcelAI\logs`, итог установки — в `install.log` там же.
- **Проверка установки:** `powershell -ExecutionPolicy Bypass -File "%LOCALAPPDATA%\Programs\ExcelAI\scripts\diagnose.ps1"`.

## Удаление

Закройте Excel, затем откройте **«Параметры Windows»** → **«Приложения»** → **«Установленные приложения»** → **«AI-панель для Excel»** → **«Удалить»**. Удаляются автозапуск сервера, регистрация в Excel и папка надстройки вместе с сохранёнными ключами.

## Mac и Excel в браузере

Для Mac и Excel в браузере есть веб-панель: программа на компьютер не ставится, панель открывается с сайта https://edgargew622-cloud.github.io/excel-ai-addin/. Модели — только через OpenRouter по вашему ключу (его получают на openrouter.ai → Keys; модели с пометкой `:free` бесплатны, но бывают перебои и дневной лимит). Ключ хранится в самой панели на этом компьютере — не вводите его на чужом.

Чего в веб-панели нет, потому что это живёт в программе для Windows: других провайдеров, памяти, прикреплённых файлов, поиска в интернете и резервной копии книги. Вся работа с книгой — формулы, сводные, диаграммы, оформление, модели, аудит — та же.

**Excel для Mac** — пошагово, с кнопкой «Скопировать»: https://edgargew622-cloud.github.io/excel-ai-addin/mac.html

1. Откройте Терминал (⌘ + Пробел → «Терминал») и выполните одну команду:
   ```
   mkdir -p ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef && curl -fsSL https://edgargew622-cloud.github.io/excel-ai-addin/manifest.xml -o ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef/am-ai.xml && echo "Готово. Перезапустите Excel."
   ```
   Она создаёт папку надстроек Excel и скачивает в неё файл описания надстройки. Программа не ставится, ничего не запускается, пароль не нужен — поэтому Mac и не спрашивает про неизвестного разработчика.
2. Закройте Excel полностью (⌘ + Q) и откройте снова. В книге: «Вставка» → «Надстройки» → «Мои надстройки» → **«am.AI (Mac и Excel в браузере)»** (на некоторых версиях «Надстройки» — на вкладке «Главная»).
3. В панели — «Ключи» → вставьте ключ OpenRouter.

Удаление: `rm -f ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef/am-ai.xml` и перезапуск Excel (ключ — кнопкой «Удалить» в «Ключах» заранее). Нужен Excel для Mac 2019, 2021, 2024 или Microsoft 365.

Команда проверяется при каждом выпуске на macOS в GitHub: берётся со страницы сайта, выполняется, файл должен встать на место и быть манифестом этой версии; затем удаление.

**Excel в браузере (Microsoft 365)**
«Главная» → «Надстройки» → «Дополнительные надстройки» → «Мои надстройки» → «Отправить мою надстройку» → выберите скачанный `manifest.xml`.

Проверено: веб-панель в Excel для Windows (без программы на компьютере, модели через OpenRouter — 4 задачи из 4) и в движке WebKit, на котором работает Excel для Mac. На настоящем Mac не проверялось — если что-то не так, напишите в Issues.

## Установка из zip-архива (для опытных)

На странице выпуска есть и архив `ExcelAI-…-win-x64.zip` — то же самое без установщика.

1. Распакуйте архив в `C:\`: правой кнопкой по архиву → «Извлечь все…» → впишите ровно `C:\` → «Извлечь». Должна получиться папка `C:\ExcelAI`, а в ней сразу — «Установить.cmd». Сервер работает из этой папки, поэтому не удаляйте и не переносите её.
2. Закройте Excel и дважды щёлкните «Установить.cmd». В конце окно напишет «Готово» и будет ждать Enter.
3. Дальше — шаги 4–5 из раздела «Установка».

Удаление: закройте Excel и дважды щёлкните «Удалить.cmd» в той же папке.
