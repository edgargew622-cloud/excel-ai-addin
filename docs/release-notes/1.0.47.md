## Что изменилось в 1.0.47

- Три режима выполнения: ручной, полуручной (по умолчанию) и автоматический. В ручном режиме каждое изменение требует подтверждения; в полуручном и автоматическом часть действий выполняется сама. В этих двух режимах чтение других листов не требует отдельного разрешения. «Только анализ» по-прежнему запрещает изменения.
- Автопродолжение больших задач и кнопка «Отменить задачу» для доступных точек отмены. Структурные изменения сбрасывают предыдущие точки; полный откат любой задачи не гарантируется.
- Улучшено построение дашбордов: плоская сводная, управление срезом (`set_slicer`), размещение объектов (`lock_objects`) и проверка общих фильтров. Обход сбоя Excel 2021 при подготовке плоской сводной.
- Базовый предел увеличен до 50 ответов модели и 15 минут активной работы; заполнение диапазона — до 200 000 ячеек. Исправлен учёт записи в пустые ячейки.
- Повтор запроса модели при обрыве связи и индикатор активности потока во время ожидания ответа.
- Уточнены инструкции для финансовых сценариев, проверки базовых допущений и оформления результатов.
- README приведён в соответствие с режимами подтверждения и ограничениями отмены.

## Платформы и проверка

Этот релиз содержит установщик и ZIP-комплект **для Windows x64**. Он выпускается из отдельной ветки; размещённая на GitHub Pages панель для Mac/Excel Online этим тегом не обновляется. Коммерческая архитектура C0 в релиз не включена.

Локально прошли 652 теста панели и 130 серверных тестов; основная и веб-сборки успешны, манифест валиден. GitHub Actions дополнительно проверяет Windows-комплект, установку и удаление перед публикацией. Новый ручной прогон в настоящем Excel в рамках подготовки релиза не выполнялся. Подтверждённых проверок на настоящем Excel для Mac и в Excel Online нет.
