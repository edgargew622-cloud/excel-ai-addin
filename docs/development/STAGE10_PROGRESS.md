## 10.1. Кнопка «Беседы» — выполнен (1.0.20)

Окно «Беседы» в обеих панелях — Windows и веб (Mac, Excel в браузере):

- список всех бесед этого компьютера: книга, название (первая просьба), дата последнего сообщения, сообщения и действия агента, **дата удаления** (последнее сообщение + 30 дней), занятое место из 2 МБ; текущая книга — первой;
- чтение любой беседы; беседа другой книги — только для чтения (история и разрешения на чтение листов привязаны к своей книге, SEC-05);
- **Windows:** «Сохранить в файл» — сервер пишет Markdown в «Документы\am.AI\Беседы» (папку «Документы» спрашивает у Windows) и называет путь; существующий файл не перезаписывается; если папка в OneDrive, панель предупреждает, что файл попадёт и в облако;
- **веб-панель:** «Скопировать текст»; если буфер обмена недоступен — текст в поле для ручного копирования;
- удаление одной беседы и всех — с подтверждением; удалена беседа открытой книги — лента очищается.

Код: `conversationStore.ts` (список, чтение без изменения хранилища, удаление всех, Markdown, имя файла), `ConversationsPanel.tsx`, `api/conversations.ts`, `server/src/conversationExport.ts` (маршрут `/api/conversations/export` за токеном панели).
