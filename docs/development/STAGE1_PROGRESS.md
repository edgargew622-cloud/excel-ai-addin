## Что сделано

- Рабочий сервер раздаёт HTTPS-панель и `/api` на порту 3000, dev-панель работает отдельно на 3100. Dev-прокси проверяет Host и Origin до передачи API-запроса.
- Выпуск содержит отдельные копии панели и серверного кода. `npm run release` выбирает новый выпуск; `npm run rollback` возвращает предыдущий для следующего запуска. Выбор хранится в `releases/current.json`.
- Супервизор берёт выбранный выпуск, не запускает второй экземпляр и перезапускает сервер после аварии. Задача `ExcelAiAddinServer` зарегистрирована в планировщике при входе пользователя.
- Журнал приложения `logs/app.log` ротируется по размеру; супервизор пишет отдельный `logs/server.log`.
- Каталог Excel обновлён; его рабочий манифест совпадает с исходным. README описывает текущий запуск.
