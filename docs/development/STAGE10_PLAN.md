# Этап 10 — беседы и то, в чём агент уступает Claude в Excel

Составлено 30 сентября 2026 года. Статус: **план, ждёт согласия пользователя**. Номер 9 занят отдельным этапом, который ведётся вне этого репозитория. Наличие этого документа не открывает агенту новых инструментов.

## Откуда этот этап

1. **Беседы.** Пользователь спросил, где хранится переписка и как её прочитать. Сейчас беседа видна, только когда открыта её книга; все беседы сразу не посмотреть, в файл не сохранить, по одной не удалить. Хранилище: `localStorage` панели, ключ `excel-ai-addin.conversations.v1`, 30 дней с последнего сообщения, не больше 20 бесед и 2 МБ (`conversationStore.ts`).
2. **Сверка с Claude в Excel.** Пользователь прислал список возможностей Claude в Excel. Сверка с кодом 30 сентября:

| Пробел | Сейчас | Решаемо у нас |
| --- | --- | --- |
| Цвета рядов и точек в диаграммах | типы, комбинированные, вторая ось, подписи, тренд — есть; цветов нет | да |
| Анализ данных: тренды, выбросы, корреляции | отдельного инструмента нет; модель читает данные и пишет формулы, на больших таблицах упирается в предел чтения | да |
| Квартили в сравнении компаний | медиана, среднее, минимум, максимум | да |
| Источник в примечании к ячейке | источник только в ответе: примечания в API — с ExcelApi 1.18, в Excel 2021 их нет | только на Microsoft 365 |
| Копирование листа | инструмент есть, Excel 2021 операцию отклоняет | только на Microsoft 365 |
| Передача диаграммы в PowerPoint | нет | вне этапа |

Там, где Claude в Excel не умеет (VBA, расписание, «Таблица данных» что-если), не умеем и мы — это вне этапа, как и в этапе 8.

## Вне этапа

- PowerPoint и Word — отдельные надстройки, фактически новые продукты.
- Магазин надстроек Microsoft — нужна учётная запись Partner Center пользователя.
- Проверка на настоящем Mac — нужен человек с Mac.

## Очерёдность работ

### 10.1. Кнопка «Беседы»

Работает в обеих панелях — Windows и веб (Mac, Excel в браузере). Ничего не уходит с компьютера.

1. **Список всех бесед:** книга (название и путь), дата последнего сообщения, сколько сообщений, **когда удалится** (дата последнего сообщения + 30 дней), сколько места занято из 2 МБ. Текущая книга — первой и отмечена.
2. **Чтение любой беседы** в панели — только чтение, даже если книга не открыта. Продолжить чужую беседу в текущей книге нельзя: история и разрешения на чтение листов привязаны к своей книге (аудит SEC-05) — так и остаётся.
3. **Сохранить в файл** (Markdown: книга, дата, сообщения пользователя, ответы агента, выполненные действия с адресами). Windows — сервер пишет файл в `Документы\am.AI\Беседы\` и называет путь; веб-панель — кнопка «Скопировать текст» (скачивание файла из панели Excel для Mac не гарантировано — замерить в WebKit и WebView2 до выбора).
4. **Удалить беседу** и **удалить все** — с подтверждением; на книгу это не влияет.
5. Предупреждение в окне: в беседах могут быть данные ячеек; файл на диске читается всеми программами под вашей учётной записью.

Проверка: тесты хранилища (список, срок, место, удаление одной и всех, повреждённая запись не роняет список); живая проверка в Excel — две книги, беседы в обеих, список, чтение чужой, файл, удаление; WebKit — окно «Беседы» и копирование.

### 10.2. Цвета в диаграммах

1. **Замер до кода:** что Excel 2021 (ExcelApi 1.14) даёт записать и что — прочитать обратно: заливка ряда (`ChartFill.setSolidColor`), цвет линии (`ChartLineFormat.color`), цвет отдельной точки, маркеры. Читать заливку API разрешает не во всех версиях — от замера зависят сверка и отмена.
2. `create_chart` и изменение готовой диаграммы: цвет каждого ряда (HEX или название из палитры), цвет отдельной точки («выдели красным максимум»), цвет линии и маркеров.
3. Сверка по тому, что Excel сообщил после записи; где цвет прочитать нельзя — карточка и ответ говорят об этом прямо. Отмена: новая диаграмма — удаление; изменение цвета готовой — возврат прежнего, если его удалось прочитать, иначе карточка предупреждает, что отмены цвета нет.

Проверка: тесты плана; живые сценарии — столбцы трёх цветов, выделение одной точки, линия на второй оси своим цветом; просьбы обычными словами на DeepSeek.

### 10.3. Анализ данных

Новый инструмент только для чтения `analyze_range`: считает панель, а не модель, по всему диапазону (чтение частями, как в поиске по книге), и возвращает числа с адресами.

1. **Тренд** по каждому числовому столбцу — по порядку строк или по столбцу дат: наклон, изменение за период, R², направление.
2. **Выбросы** — по межквартильному размаху (и z-оценке для больших рядов): адреса ячеек, значения, границы.
3. **Корреляции** между числовыми столбцами: коэффициент Пирсона, число пар; сильные связи — отдельно, с оговоркой «связь не значит причину».
4. **Сводка:** количество, среднее, медиана, квартили, минимум, максимум, пропуски.
5. Модель объясняет результат словами; записать итог в книгу (формулами КОРРЕЛ, КВАРТИЛЬ и т. п.) — отдельно, через карточку, по просьбе пользователя.

Проверка: тесты расчётов на эталонных данных (сверка с формулами Excel на тех же числах); живые просьбы «найди выбросы», «есть ли тренд», «что с чем связано» на таблице в несколько тысяч строк.

### 10.4. Квартили в сравнении компаний

`add_multiples`: строки 1-го и 3-го квартиля формулами КВАРТИЛЬ.ВКЛ рядом с медианой и средним; пустые мультипликаторы (отрицательная EBITDA) в квартили не попадают — как уже в медиану. Проверка: тесты шаблона, живой сценарий на пяти компаниях.

### 10.5. Мелочи

1. Windows: модель по умолчанию в OpenRouter — Claude Sonnet 5.5 вместо Sonnet 5 (цена та же, в проверке быстрее).
2. Mistral Small в веб-панели: оставить или убрать — решение пользователя; перед выпуском — ещё одна проверка.

### 10.6. Подготовка к Microsoft 365 — по решению пользователя

Код за проверкой версии API: **примечание к ячейке** (инструмент и источник из интернета в примечании) и **копирование листа** — выдаются модели, только если Excel поддерживает (ExcelApi 1.18 и 1.8 с работающим `copy`). В Excel пользователя не проверить — только тесты; в отчёте — «не проверено в Excel».

## Правила, которые переходят из этапа 8

- Сначала замер поведения Excel, потом код; замер — в отчёт `STAGE10_PROGRESS.md`.
- Каждый изменяющий инструмент — через реестр планов: план, карточка, проверка состояния, запись, обратное чтение, отмена.
- Возможности проверяются по версии API установленного Excel; неподдерживаемое модели не выдаётся.
- Найденный дефект показывается до исправления.
- Каждый срез: автоматические тесты, живая проверка в Excel, просьбы обычными словами на DeepSeek; для веб-панели — ещё WebKit.
- Каждый выпуск — через GitHub Actions; архив и сайт проверяются на ключи до публикации ссылки.

## Критерии готовности

Срез закрыт, когда проверен в Excel (веб-части — ещё и в WebKit), записан в `STAGE10_PROGRESS.md` с замерами, README обновлён, выпуск опубликован. Этап закрыт, когда закрыты 10.1–10.5 (10.6 — если пользователь его включил) или пункты явно перенесены решением пользователя.
